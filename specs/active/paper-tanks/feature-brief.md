# Feature Brief: Paper Tanks (танчики на бумаге)

**Task ID:** paper-tanks  
**Created:** 2026-09-12  
**Status:** Upgraded to SDD 6.0

---

## Problem Statement

Нужно вернуть советские «танчики на бумаге» на телефон, не имитируя сгиб листа (на экране он не работает). Стрельба берётся из морского боя: скрытая расстановка и точный выстрел по клетке. Двое играют по одной Wi‑Fi, сервер крутится на компьютере, клиент — страница/PWA на телефоне. Визуал — старый тетрадный лист в клетку и небрежный синий стержень.

## Target Users

- Двое за одним столом / в одной квартире: открыли игру на телефонах, компьютер в той же сети держит комнату.
- Люди, которые помнят тетрадный лист, шариковую ручку и морской бой; не геймеры-соревнователи.
- Язык интерфейса v1 — русский.

## Core Requirements

### Must Have

- [ ] Поле выглядит как выцветший советский тетрадный лист в клетку (поля игроков — две «половины», как после сгиба).
- [ ] Танки — плоские спрайты/SVG «синяя шариковая, нарисовано наспех»: корпус, башня, дуло, лёгкая дрожь линии.
- [ ] Расстановка скрыта (туман войны). Своё поле видно полностью, чужое — пустая клетка, пока туда не выстрелили.
- [ ] Выстрел как в морском бою: игрок указывает клетку на поле соперника, ответ — **мимо / ранен / убит**.
- [ ] Попадание даёт ещё один выстрел; промах передаёт ход. Партия до уничтожения всего флота.
- [ ] Сеть 1vs1 по LAN: сервер на компьютере, телефоны заходят по адресу/QR в той же Wi‑Fi.
- [ ] Статистика в партии и после: чей ход, сколько танков осталось у каждого (числом, не позициями), выстрелы, точность; после боя — итог и карта обстрела.

### Nice to Have

- [ ] Движение целого (не раненого) танка на 1 клетку после своего промаха.
- [ ] Попадание только в дуло = ранение, не убийство.
- [ ] Лимит времени на ход (~20 с) — лёгкий темп, без аркады.
- [ ] Установка на домашний экран (настоящий PWA/HTTPS); в v1 достаточно мобильного браузера.
- [ ] Разный цвет стержня у игроков; нарисованный «взрыв» при убийстве.
- [ ] Публичный матчмейкинг и игра через интернет.

## Game Mechanics (v1)

Два слоя правил, сознательно не смешанные: **бумага даёт вид и ритм хода**, **морской бой даёт скрытность и клетку**.

### Поле и флот

| Параметр | v1 |
|----------|----|
| Сетка игрока | 12×16 клеток (одна тетрадная страница, удобно на телефоне) |
| Ориентация танков | только по клеткам, горизонталь/вертикаль |
| Касание | танки **не соприкасаются** даже углами (школьный морской бой) |
| Флот | 1×4, 2×3, 3×2, 2×1 — всего 8 единиц / 20 клеток |

Флот смешивает «классический танк на две клетки» с разнобоем длин, чтобы поиск не был угадайкой одинаковых двоек.

### Фазы

1. **Комната** — хост на ПК создаёт сессию, показывает QR и `http://<lan-ip>:<port>`. Два телефона заходят, ник опционален.
2. **Расстановка** — каждый расставляет флот на своём поле, жмёт «Готов». Пока оба не готовы, чужое поле закрыто.
3. **Бой** — жеребьёвка первого хода. Игрок стреляет по клеткам тумана. Мимо → ход сопернику. Ранен/убит → ещё выстрел.
4. **Конец** — у одной стороны 0 живых единиц. Экран итога, кнопка «ещё партия» в той же комнате.

### Динамика без перегруза

В v1 динамика только такая, чтобы партия не была сухим обменом клетками:

- Серия выстрелов после попаданий (как на бумаге и в морском бою).
- Живой счётчик оставшихся танков у обоих — давление без открытия позиций.
- Сообщение **убит** при полном уничтожении единицы — охотник знает, что пора менять цель.

Всё остальное (ход танков, ранение дула, таймер, пристрелка) — следующий слой, не v1.

### Статистика

**Во время партии (компактная полоса):** чей ход, танки живые `ты N — соперник M`, выстрелы, % попаданий, результат последнего выстрела.

**После партии:** победитель, длительность, число ходов, точность обоих, попадания/промахи, мини-карта своего обстрела чужого поля.

## Technical Approach

Отдельный игровой репозиторий (этот репозиторий — SDD-инструмент, не игра). Клиент — Vue 3, мобильный браузер / заготовка PWA: CSS-клетка тетради, SVG чернильных танков, своё поле и поле тумана. Сервер — небольшой процесс на компьютере хоста (Node + WebSocket или эквивалент): комната на двоих, синхрон фаз, валидация выстрела на сервере (клиенту нельзя «подглядеть» флот). Телефоны ходят на LAN-IP машины, не на `localhost` телефона: процесс слушает `0.0.0.0`, UI хоста показывает QR.

Игрового кода и UI-паттернов в текущем репозитории нет — конвенции задаём с нуля.

**Patterns to Follow:**
- Нет существующих игровых паттернов в `spec-kit-command-cursor` — новая конвенция.
- SDD: бриф здесь → код в отдельном проекте → `/evolve paper-tanks` при находках.
- Пользовательские предпочтения стека: Vue 3 для клиента; Laravel для этой LAN-игры избыточен.

**Key Decisions:**
- Туман войны, не видимые танки соперника: иначе точный выстрел по клетке тривиален.
- LAN 1vs1, не интернет: хост = компьютер в той же Wi‑Fi, клиенты = телефоны.
- v1 в мобильном браузере по HTTP в LAN; полноценный installable PWA откладываем (нужен HTTPS).
- Механика наращивается слоями; v1 не включает движение и таймер.
- Счётчик живых танков без позиций: информация как в аккуратном морском бое, без спойлера расстановки.

## Success Criteria

- [ ] Два телефона в одной Wi‑Fi с компьютером-сервером проходят расстановку и полную партию до победы.
- [ ] Соперник не видит чужие танки до попаданий; подделка выстрела с клиента отвергается сервером.
- [ ] Поле читается как тетрадь в клетку, танки — как синяя ручка.
- [ ] В бою видны счётчики и чей ход; после боя — итог и точность.
- [ ] Партия не требует аккаунта, интернета и магазина приложений.
