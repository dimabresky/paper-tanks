# Танчики на бумаге

Сетевые «танчики» 1vs1: тетрадный лист 16×22, синяя ручка, стрельба как в морском бое. Компьютер — стол (HTTP + WebSocket на порту 8787); телефоны заходят по QR в той же Wi‑Fi. Телефон с телефоном напрямую не соединяется.

Спека фичи: `specs/active/paper-tanks/`.

## Требования

- Node.js 22.12+
- [pnpm](https://pnpm.io/) 9+ (если нет глобально: `npx pnpm@10 install`)

## Запуск

```bash
pnpm install
pnpm dev
```

Открой на компьютере `http://127.0.0.1:8787/` — там QR и адреса LAN, пока свободно хотя бы одно место.

Телефоны открывают `http://<ip-компьютера>:8787/` **в той же Wi‑Fi**. `localhost` на телефоне — это сам телефон, туда заходить не нужно.

Порт: **8787**. Слушает `0.0.0.0`.

## Если телефон не открывает страницу

1. Компьютер и телефоны в одной Wi‑Fi, не в гостевой сети.
2. macOS: Система → Сеть → Брандмауэр — разрешить входящие для Node / Terminal на порт 8787.
3. Выключи «изоляцию клиентов» (AP isolation / Client isolation) на роутере.
4. Если в QR попал не тот IP (VPN) — открой другой адрес из списка на хосте.
5. Адрес `169.254.x.x` игра сама не предлагает.

Интернет не нужен (кроме шрифта Google Fonts; без сети останется запасной шрифт). Когда оба игрока уже открыли страницу и сидят за столом, WAN на компьютере можно выключить — партия идёт по LAN.

Это **не** устанавливаемое PWA: браузер не ставит приложение с `http://192.168.x.x`. Открывай в Safari или Chrome.

## Игра

1. Двое заходят (можно одно место с компьютера). Карточка QR скрывается, когда оба места заняты.
2. Расстановка: перетащи фигурки с лотка на лист (2×4, 2×3, 1×2, 1×1), тапни танк и нажми «Повернуть», либо «Расставить как получится» → **Готов**.
3. Поле — только квадратные клетки; масштаб кнопками +/− или щипком (клетка по умолчанию ~22px, лист прокручивается).
4. После готовности на своём листе появляются ёлки и ящики; на чужом они скрыты, пока туда не выстрелили.
5. Стрельба по клеткам тумана. Попадание в танк — ещё выстрел, промах или ёлка — ход соперника, ящик открывает соседние клетки.
6. «Ещё партия» без нового QR.

## Проверки

```bash
pnpm test
pnpm typecheck
pnpm test:e2e
```

E2E поднимает сервер сам и играет двумя окнами Chrome.

## Сборка «как для стола»

```bash
pnpm start
```

Собирает клиент и раздаёт его с того же порта 8787.
